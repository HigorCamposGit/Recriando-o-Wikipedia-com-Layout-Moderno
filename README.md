# Recriando o Wikipedia com Layout Moderno.

Repositório criado como parte do desafio da **DIO**, para o curso de `Formação HTML Web Developer` com o objetivo de construir uma enciclopédia moderna (estilo Wiki) sobre a aclamada série de suspense e ficção científica `Dark` da Netflix, aplicando conceitos avançados de `HTML5 semântico` e `acessibilidade web`.

---

## 🚀 Sobre o Projeto.

O projeto foi desenvolvido para fixar técnicas essenciais de estruturação web, substituindo códigos legados baseados em caixas genéricas (DIVs) por uma arquitetura totalmente semântica. A página aborda a sinopse geral da série Dark, as 3 temporadas, detalhes de produção e conta com navegação interna por âncoras. Seguindo o padrão aprendido nas aulas.

♿ Acessibilidade (`A11y`) Aplicada no Projeto.
---
Na tecnologia e no desenvolvimento web, `A11y` significa projetar e desenvolver sites, aplicativos e sistemas para que pessoas com deficiência (visual, auditiva, motora ou cognitiva) possam navegar, interagir e compreender o conteúdo com total autonomia, muitas vezes utilizando tecnologias assistivas como leitores de tela.

Pensando nas boas práticas exigidas em avaliações e no uso de ferramentas assistivas, o projeto incorporou:

HTML5 Semântico: Uso correto de tags como `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>` e `<footer>`, garantindo que leitores de tela compreendam a hierarquia e o propósito de cada bloco da página.

Imagens Descritivas: A imagem principal utiliza a tag estruturada `<figure>` combinada com `<figcaption>` e atributos `alt="..."` bem descritivos, permitindo que pessoas com deficiência visual saibam exatamente o conteúdo exibido.

Navegação e Rótulos: Inclusão de atributos aria-label nas seções de navegação lateral para orientar softwares leitores (como o `NVDA`).

Validação: Estrutura otimizada para passar com sucesso em ferramentas de auditoria de código, como a extensão `WAVE` para Google Chrome.
